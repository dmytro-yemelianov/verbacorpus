# Хендовер інтеграції корпусів Verba Corpus

Стан на 1 листопада 2026 року. Наступне завдання — завершити спільний каталог
Verba Corpus і підключення окремих корпусів. Публічно працює корпус прислів’їв;
каталог і «Українська без табу» реалізовані локально, UPA Archive має окремий
локальний сайт. Цей хендовер не означає дозволу на розгортання чи зміну DNS.

## Де продовжувати роботу

Координація парасольки залишається в `dmytro-yemelianov/verbacorpus`, оскільки
тут уже реалізовано каталог і навігацію. Новий репозиторій для хендовера не потрібен.
Виділення окремого репозиторію парасольки має сенс під час фактичного перенесення
головної сторінки на каталог, а прислів’їв — на окремий сайт. Це наступна
архітектурна зміна, яку ще не виконано.

| Репозиторій | Локальний каталог відносно Verba | Гілка і поточна ревізія | Відповідальність |
| --- | --- | --- | --- |
| [verbacorpus](https://github.com/dmytro-yemelianov/verbacorpus) | `.` | `integrate/bez-tabu`, база хендовера `746a2cc` | Публічний Worker прислів’їв, каталог, копія даних і браузерний перегляд «Без табу», бот |
| [ua-bez-tabu](https://github.com/MurzikVasilyevich/ua-bez-tabu) | `../ua-bez-tabu` | `integrate/verbacorpus`, `6e5f64a` | Канонічний `synonyms.csv`, експортер словника |
| [upa-archive](https://github.com/dmytro-yemelianov/upa-archive) | `../upa-archive` | `site-local-preview`, `2f94f0d` плюс незакомічені зміни | Канонічні орнаменти, геометрія, окремий сайт та API |

Ревізії описують локальний стан, а не підтвердження публікації цих гілок на GitHub.
Перед початком звірити `git status` у кожному репозиторії. В UPA багато поточних
змін у генераторі, перегляді та тестах; їх не скидати й не підміняти старим комітом.

## Що вже реалізовано локально

### Каталог корпусів

- `app/content/corpora.json` — реєстр `slovo`, `bez-tabu`, `upa`.
- `app/content/corpora.html` і `app/build_corpora.mjs` — шаблон та генератор.
- `app/public/corpora.html`, `app/public/data/corpora.json` — результат збірки.
- `app/src/client/chrome.ts` — додає «Корпуси» в навігацію.
- `app/build.mjs` — збирає каталог разом із застосунком.

`slovo` поки посилається на `/`, «Без табу» — на `/bez-tabu/`, UPA має `href: null`
і статус підготовки. Статистика UPA в генераторі вписана вручну: 167 орнаментів,
38 сторінок. Каталог не імпортує актуальні дані UPA і не перевіряє їхню версію.

### Українська без табу

Словник містить 2 000 вихідних рядків, 1 995 унікальних рядків, 55 іменованих
термінів і 12 груп. Є картки, пошук, фільтри, граф зв’язків, URL зі станом і
експорти CSV, JSON та XML. Це вибірка відповідників із проєкту на основі книжки
Лесі Ставицької, а не повний словник із визначеннями та цитатами.

Дані копіюються під час явного запуску `app/sync_bez_tabu.py` з сусіднього
репозиторію в `app/public/bez-tabu/data/`. Звичайна збірка працює без сусіднього
репозиторію, перевіряючи SHA-256 файлів за `provenance.json`. Автоматичної
синхронізації з upstream немає. Усі 5 повторних рядків і 26 рядків без терміна
збережено; `sourceRow` не є стабільним ID після переставлення рядків.

Пошук словника локальний у браузері. Нових серверних API та семантичного
індексу для нього немає. Інтерфейс український. Офлайн-кеш залежить від service
worker головного сайту; сам словник його не реєструє.

Повні деталі та попередні результати браузерних перевірок:
[BEZ-TABU.md](BEZ-TABU.md).

### UPA Archive та оздоблення

Актуальне джерело — `../upa-archive/data/patterns.v3.json`: 167 орнаментів,
геометрія заливок і стібків та походження від сторінок джерела. Окремий сайт
лежить у `../upa-archive/site/`. Його `wrangler.jsonc` має назву
`upa-local-preview`, вимкнені `workers_dev` і `preview_urls`, без доменних маршрутів.
Поточні умови публікації описані в `../upa-archive/site/README.md` і
`../upa-archive/docs/superpowers/specs/2026-10-22-upa-verbacorpus-site-design.md`.
Питання публічного поширення даних і джерельних зображень там залишено відкритим.

У Verba зараз три різні способи використання орнаментів:

1. `app/public/data/embroidery-archive.json` — стара вибірка 123 матриць для
   ефекту наведення. `app/src/client/main.ts` малює квадратні клітинки; схема
   `{r,c,m}` не містить повної геометрії нового UPA.
2. `app/src/shader/embroidery.ts` — 38 зафіксованих бордюрів для карток і GIF;
   `app/src/embroidery-css.ts` використовує їх для CSS-оздоблення.
3. `editorial/telegram/ornaments/` — нові підготовлені приклади з v3 через
   `chartSvg`, з маніфестом походження та хешем корпусу. Каталог `editorial/`
   наразі незакомічений і не підключений до звичайної збірки або бота.

Старий `app/scripts/build-embroidery-archive.mjs` читає абсолютний шлях
`/home/dmytro/github/dyco/assets/ukrainian-embroidery-corpus/unique_patterns.jsonl`.
Перед оновленням оздоблення замінити цей імпорт на відтворюваний знімок із UPA,
зберігши геометрію, ID орнаменту, версію й атрибуцію.

## Межі поточної інтеграції

`app/src/index.ts` завантажує лише прислів’я, пояснення та їхні метадані.
API v1, Vectorize, семантичний пошук і `app/src/telegram.ts` працюють із
прислів’ями. Спільного пошуку, універсального API корпусів, спільних ID та
автоматичного добору Telegram-публікацій зі словника чи UPA ще немає.

Піддомени `slovo.verbacorpus.org` та `upa.verbacorpus.org` — запланована схема,
а не поточна інфраструктура. Перенесення прислів’їв потребуватиме сумісності
старих `/p/*`, `/s/*`, `/card/*` та `/api/*`, включно з методом і тілом запитів
вебхука. Домен словника ще не обраний; готовий шлях — `/bez-tabu/`.

## Налаштування які треба зберегти

- У `app/wrangler.jsonc` є незакомічене вимкнення новинного cron
  `0 5,8,11,14,17 * * *` за вказівкою власника. Залишений `0 6 * * *` для
  прислів’я дня. Не відновлювати новинний cron під час злиття чи розгортання.
  Перед розгортанням звірити фактичні тригери Cloudflare; HTTP-аудит їх не перевіряє.
- Зберегти bindings AI, Vectorize `proverbs-bge-m3-v2` та NEWS_KV, чинні домени
  й секрети Worker. Токени не переносити в документацію або git.
- Не змінювати дані джерел, дублікати та походження заради уніфікації інтерфейсу.
  Ліцензія CC BY 4.0 корпусу прислів’їв автоматично не поширюється на інші корпуси.
- `editorial/` містить поточні Telegram-напрацювання. Не додавати весь каталог
  до коміту хендовера без окремого перегляду його вмісту.

## Порядок завершення інтеграції

1. Відновити залежності Verba, зібрати гілку інтеграції й перевірити каталог,
   словник та навігацію на локальному Worker. Не перебудовувати канонічний корпус
   прислів’їв або знімок словника без потреби.
2. Підготувати публікацію готового каталогу і «Без табу» на чинному домені.
   Узгодити правдиві статуси карток; поки UPA локальний, залишити його в підготовці.
   Перевірити сумісність наявного сайту, API, карток, кешу та cron.
3. Завершити підготовку окремого UPA-сайту й умов його публікації. Після запуску
   додати його адресу в реєстр; замінити вручну вписану статистику перевіреним
   маніфестом даних. Оновлювати оздоблення з актуального UPA окремим кроком.
4. Якщо головна сторінка стає парасолькою, окремо реалізувати переїзд прислів’їв
   і перенаправлення старих адрес. Не поєднувати цей переїзд із першою публікацією
   вже готового словника без необхідності.
5. Розширити Telegram на корпуси після появи публічних посилань. Власник хоче
   оголошення про парасольку, публікації з усіх корпусів, вікторини як справжні
   Telegram-опитування з варіантами відповідей та різні формати. Шлях до джерела
   і атрибуція мають супроводжувати матеріал. Новинний cron лишається вимкненим.

## Команди для продовження

Після очищення диска `app/node_modules` видалений як відновлювана залежність.
Відновлення зі збереженого `package-lock.json`:

```sh
cd /Users/dmytro/github/verbacorpus
git status --short
git branch --show-current
cd app
npm ci
python3 -m unittest discover -s test -p 'test_sync_bez_tabu.py' -v
npm run build
./node_modules/.bin/tsc -p tsconfig.corpora.json
npm test
./node_modules/.bin/wrangler dev --local --port 8791 --inspector-port 9235
```

За потреби оновлення знімка словника використати послідовність експорту й імпорту
з [BEZ-TABU.md](BEZ-TABU.md), а не редагувати копії в `public/` вручну.
Для UPA виконувати команди з його `site/README.md` у власному репозиторії;
поточні незакомічені зміни мають залишитися на місці.

## Перевірки та умови готовності

1 листопада повторно пройшли 2 unittest імпорту словника; SHA-256 усіх файлів
знімка правильні, CSV збігається з сусіднім джерелом. HTTP-результати наведені
в доданому JSON. Повторна збірка JS та браузерні тести до цього аудиту не входили.
157 Vitest-тестів і браузерні результати в `BEZ-TABU.md` належать попередній
перевірці інтеграції; загальний typecheck тоді мав 35 відомих діагностик baseline.

Після наступних змін перевірити:

- каталог і словник відповідають HTTP 200, картки ведуть на доступні корпуси;
- у словнику лишилося 2 000 рядків, працюють фільтри, граф, URL і завантаження;
- пошук прислів’їв, API, короткі посилання, картки та бот зберігають поведінку;
- мобільний перегляд, українська й англійська навігація, оновлення service worker;
- статистика і статус кожного корпусу відповідають його фактичній версії;
- новинний cron вимкнений, а прислів’я дня не вимкнене випадково;
- UPA має адресу, атрибуцію та посилання на походження після публікації.
