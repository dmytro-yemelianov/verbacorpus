## 1. Мета й контекст

Зробити картки Verba Corpus візуально виразними для соцмереж і сайту, виділяючи **«гачок»** (ключовий образ, контраст або пуант прислів'я) за допомогою піксельної типографіки Nasinnia та рамок UPA.

Основа:
- Корпус `pro` (`48 787` записів, `v1.0.3` з очищеною пунктуацією) та `contra` (`2 000` записів).
- Макет-прототип: [styles.html](../../handover/2026-11-26-card-styles/styles.html).
- Пробні прогони на 40 та 200 прислів'ях підтвердили 100% дослівної точності на **Gemini 4 Hydrogen** (на 40/40) та 97.5% на `flash_lite` до ретраїв (на 200/200). Рішення Дмитра: повний прогін **Pass C** на **Gemini 4 Hydrogen** пакетами через `run_workflow`.

## 2. «Гачок» (Pass C збагачення корпусу)

### 2.1 Визначення та правила валідації
Гачок (`hook`) — це підрядок тексту прислів'я, що найбільше чіпляє увагу читача.

Обов'язкові обмеження:
1. **Точний суцільний підрядок** поля `text` (збережено діалектну орфографію, регістр, апострофи й розділові знаки всередині фрагмента).
2. **Цілі слова** (межі слів не можуть розривати слово всередині).
3. **Довжина: 1–4 слова.**
4. **Без фінальної крапки** в кінці гачка.
5. **Не закінчується службовим словом** (`а`, `і`, `й`, `та`, `не`, `що`, `на`, `в`, `у`, `до`, `з`, `із`, `зі`, `за`, `по`, `від`, `для`, `про`, `при`, `над`, `під`, `без`, `чи`, `бо`, `як`, `то`, `же`, `ж`, `би`, `б`, `ні`).
6. Якщо для прислів’я не існує підрядка, який задовольняє всі правила, `hook` може бути порожнім рядком; `hook_source` у такому разі — `rule`.

### 2.2 Конвеєр Pass C (`enrich/`)
1. **Пакети:** формуються батчі з `corpus.csv` (по 100 записів, файловий I/O у `enrich/pass_c/` із відновленням з місця зупинки — уже збережені й валідні батчі пропускаються).
2. **Модель:** Gemini 4 Hydrogen через `run_workflow` (паралельні хвилі з негайним збереженням кожного батча на диск).
3. **Валідація та відновлення:**
   - Кожна відповідь перевіряється детермінованим валідатором за правилами §2.1.
   - Усі невалідні / пропущені ID збираються в ремонтний раунд (1 повторний прогін моделлю).
   - Якщо й після ретраю запис не пройшов валідацію — застосовується **запасне правило** (`hook_source: "rule"`): детерміновано вибирається допустимий фрагмент до трьох слів, спершу після останньої коми, потім з решти тексту. Якщо допустимого фрагмента немає, зберігається порожній рядок.
4. **Результат у даних:**
   - Поля `hook` та `hook_source` (`"model"` | `"rule"`) додаються в експорт корпусу (`corpus.csv`, `corpus.json`, `app/public/data/proverbs.json`) та віддаються в `/api/v1/proverb/:id` (і через шлюз `verba-api` у `/v1/pro/items/:id`).
   - Для `contra` (`2 000` записів): текст картки формується як `${synonym} — ${term}` або окремий короткий зворот; `hook` для `contra` може використовувати `synonym` або окремий Pass C за тією ж схемою.

## 3. Стилі карток та вирівнювання

### 3.1 Погоджені 8 стилів (`style`)
Усі кольори — виключно з палітри UPA (`A #DC143C`, `D #0A0A0A`, `F #E3C20B`, папір `#f4f1e8`, чорнило `#232520`):

| Ключ | Назва | Опис |
|---|---|---|
| `base` | Базовий | Один колір чорнила, один розмір шрифту (без виділення гачка) |
| `color` *(default)* | Гачок кольором | Гачок виділено червоним `A` (`#DC143C`) |
| `big` | Гачок більший | Зачин дрібнішим масштабом, гачок окремим рядком `×1.6` |
| `shadowS` | Тінь коротка | Гачок `A`, тінь `D` на пів пікселя гліфа вниз-праворуч |
| `shadowD` | Тінь униз | Гачок `A`, тінь `D` на пів пікселя гліфа лише вниз |
| `stitch` | Хрестик | Кожен піксель гачка рендериться стібком «х» кольором `A` |
| `invert` | Інверсія | Темне поле `D`, основний текст папером, гачок жовтим `F` (`#E3C20B`) |
| `marker` | Маркер | Гачок на червоній смузі `A`, літери гачка кольором паперу |

*(Відкинуті варіанти: дизеринг, тінь на 2 px, об'ємна тінь, обидва контури — не використовуються.)*

### 3.2 Вирівнювання (`align`) — 5 варіантів
- `left` *(default для ручних рецептів або за `seed`)* — по лівому краю
- `center` — по центру
- `right` — по правому краю
- `stairR` — драбинкою вправо (пропорційний зсув рядків від 0 до правого краю)
- `stairL` — драбинкою вліво (пропорційний зсув від правого краю до 0)

### 3.3 Типографіка та пунктуація на картках
- Розділові знаки завжди приклеєні до попереднього слова і не переносяться на початок нового рядка.
- Тире `—` приклеюється до попереднього слова нерозривним пробілом (`\u00A0—`), щоб не відриватися на новий рядок.
- Фінальна крапка в кінці тексту прибирається за замовчуванням (налаштування рецепта / рендера).

### 3.4 Параметри API карток
У `/card/render.{png,gif,json}` (Verba) та `/v1/cards/{textId}.{png,gif,json}` / `/v1/cards/random.*` (шлюз `verba-api`):
- `style`: один із 8 ключів (`base`, `color`, `big`, `shadowS`, `shadowD`, `stitch`, `invert`, `marker`). За замовчуванням `color` (для `random` і щоденних карток — обирається детерміновано за `seed`). Невідоме значення → `400`.
- `align`: один із 5 ключів (`left`, `center`, `right`, `stairR`, `stairL`). За замовчуванням `left` (для `random` — за `seed`). Невідоме значення → `400`.
- `hook`:
  - `auto` *(default)* — бере поле `hook` із запису корпусу; якщо немає, рендерить без виділення.
  - `none` — примусово вимикає виділення гачка (аналог `base` для тексту).
  - довільний рядок — має бути точним суцільним підрядком тексту картки, інакше `400 invalid_hook`.

## 4. Етапи виконання

1. **Pass C (гачки для `pro`):** підготувати батчі з `corpus.csv` (`v1.0.3`), прогнати на **Gemini 4 Hydrogen** через `run_workflow` зі збереженням на диск, виконати ретрай + фолбек `rule`, змерджити `hook` та `hook_source` у дані корпусу (`v1.0.4` або в межах оновлення даних).
2. **Verba card renderer (`app/src/card/`):** реалізувати `style`, `align`, `hook`, нерозривне тире та приховування фінальної крапки, додати тести в `app/test/card-render.test.ts`.
3. **Gateway (`gateway/`):** прокинути `style`, `align`, `hook`, детермінований вибір `style`/`align` за `seed` у `random` та оновити `openapi.json`.
4. **Перевірка й розгортання:** після тестів і підтвердження Дмитра — PR/злиття в `main` (CI розгортає Verba) та ручний деплой `gateway/`.
