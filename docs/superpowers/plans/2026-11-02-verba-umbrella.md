## Реалізований результат

Каталог має п’ять напрямів і працює на `/` та `/corpora`. Прислів’я відкриваються
на `/pro/`, словник на `/contra/`; редакція використовує 3 опубліковані статті.
Шрифтовий зразок містить 168 точних гліфів Cozette та MIT-ліцензію. Окремий
авторський набір містить 12 іконок 16×16, JSON, SVG, PNG та SVG-спрайт.
UPA представлений перевіреними метаданими 167 орнаментів, без сканів і матриць.

Звичайна збірка не потребує сусідніх репозиторіїв. `npm run sync-corpora` —
явна команда оновлення знімків; `npm run build` перевіряє їхні хеші.
Новинний cron лишається вимкненим; `0 6 * * *` збережено.

## Перевірки 2 листопада

- `npm ci` і `npm run build` — успішно.
- `npm test` — 173 Vitest-тести та 4 Node-тести пройшли, включно з регресійною
  перевіркою локального протоколу коротких посилань.
- `python3 -m unittest discover -s test -p 'test_sync_bez_tabu.py' -v` — 2 тести пройшли.
- `tsc -p tsconfig.corpora.json` — успішно. Повний `tsc --noEmit` має 35
  попередніх діагностик у старому коді й тестовій конфігурації; нових діагностик немає.
- `wrangler deploy --dry-run` — успішно; публічного розгортання не виконано.
- [HTTP-перевірки](../../umbrella-http.json) — сторінки, JSON, SVG, PNG,
  прислів’я, коротке посилання, пошук і хеші публічних знімків.
- [Браузерний результат](../../umbrella-browser.json) — 12 переглядів при
  1280 і 390 px без переповнення та необроблених винятків; пошук і граф словника,
  українські символи, явний відсутній символ, зміна теми й кеш прислів’їв при
  заблокованій мережі. У pane `navigator.onLine` лишався `true`, тому блокування
  підтверджено окремим невдалим API-запитом, а не лише значенням цієї властивості.

## Локальний перегляд

```sh
cd /Users/dmytro/github/verbacorpus/app
npm ci
npm run build
npm test
./node_modules/.bin/wrangler dev --local --port 8791 --inspector-port 9235
```

Головна: <http://localhost:8791/>. Цільові піддомени ще не мають DNS і прив’язок;
їхня маршрутизація підготовлена й перевірена тестами. Перед публікацією зберегти
поточні bindings, секрети, вимкнений новинний cron та права кожного знімка.

Браузерна перевірка через відкриту pane Paradev: `node app/scripts/check-umbrella-browser.mjs <workspace-id> <pane-id>` із кореня репозиторію. Скрипт залишає мережу ввімкненою після перевірки й зберігає JSON та PNG у `docs/`.
