# Абсолютний єдиний субпіксель Verba (The 8px Quantum)

## 1. Закон 100% однакового субпікселя для ВСІХ елементів

Усі картки Verba будуються на **єдиній дискретній сітці з квантом $8 \times 8$ px**:

| Елемент | Розмір субпікселя | Як реалізовано на картці |
| :--- | :---: | :--- |
| **1. Рамка по всьому периметру (UPA)** | **$8 \times 8$ px** | **Строго 1:1** без жодного масштабування $1:N$. Кожен стібок патерну — рівно 1 клітинка $8 \times 8$ px (автентичний патерн `p08_R_b04` на 5 рядків = 40 px смуга з усіх 4 боків). |
| **2. Кутові зʼєднання (45° Miter Join)** | **$8 \times 8$ px** | Усі 4 кути зʼєднуються симетричним діагональним зрізом (45° miter seam): суцільна чорна базова лінія (`DDDDDDDD`) замикається в ідеальний прямокутний контур без розривів. |
| **3. Нативні літери тексту (Прямий рендер)** | **$8 \times 8$ px** | **Пряма растеризація 1-бітних гліфів шрифту** (`cozette`) без жодного пересемплювання. Кожен біт гліфа — це рівно 1 клітинка $8 \times 8$ px. Кернінг та міжлітерні інтервали беруться напряму з нативних метрик (`advanceX`). |
| **4. Єдиний QR-код** | **$8 \times 8$ px** | Строго 1:1. Кожен модуль QR-коду — рівно 1 клітинка $8 \times 8$ px ($29 \times 29$ клітинок = $232 \times 232$ px). |
| **5. Процедурні шейдери тла** | **$8 \times 8$ px** | **Строго 1:1 на тій самій сітці**. Кожна точка шуму або переплетіння — рівно 1 клітинка $8 \times 8$ px, захищена ореолом 24 px навколо тексту. |

## 2. Аналіз GL-шейдерів у сусідніх репозиторіях

При дослідженні репозиторіїв виявлено наступні графічні патерни:
1. **`shader-wallpaper` (`Shaders.metal`):**
   - **CRT Pillow Distortion:** радіальне викривлення координат $uv \cdot (1 + \mu \cdot \|uv\|^2)$ для імітації опуклого скляного екрана.
   - **Багатофазний дрейф:** комбінація несумірних синусоїд для плавного органічного дрейфу без помітних повторів: `drift = sin(t * 0.12) * 0.5 + sin(t * 0.07) * 0.25`.
   - **Хроматична аберація та люмінофорний післясвітіння (Afterglow):** затримка спаду яскравості на фосфорі.
   - **Сканувальні лінії (Scanlines) та фазовий джитер.**
2. **`retro-pixel-factory` (`graphics/noise.ts`):**
   - Швидка таблична 2D-генерація шуму (таблиця 1024 значень) з кубічним сплайном Ерміта $u = f^2(3 - 2f)$.
3. **`media-glitch` (`engine.py`):**
   - Стохастичні побітові зсуви байтових каналів, силісінгові скановані смуги.

## 3. Як створити не рубану зациклену анімацію (Seamless Looping Invariants)

«Рубаний» стик в анімації виникає через три речі:
1. **Дробовий фазовий стрибок:** якщо зсув патерну між останнім кадром і нульовим не дорівнює точній довжині рапорту ($P$).
2. **Нерівномірний крок (Rounding Jitter):** коли довжина зміщення не ділиться націло на кількість кадрів.
3. **«Кипіння» палітри (Dither Boiling):** якщо для кожного кадру генерується окрема адаптивна палітра (у GIF).

### 5 законів ідеальної безшовної анімації (WebP):

1. **Цілочисельний резонанс рапорту (Stitch-Locked Phase):**
   - Рапорт патерну `p08_R_b04` дорівнює $P = 8$ стібків ($64$ px).
   - Кількість кадрів у циклі — строго $32$ (тривалість $3.2\text{ с}$ при 10 fps). За повний цикл рамка зміщується рівно на $8$ стібків ($0.25$ стібка/кадр = $2\text{ px}$ на кадр).
   - На межі кадру 31 $\to$ 0 зсув становить рівно $8$ стібків $\equiv 0 \pmod 8$. **Стрибок дорівнює нулю.**
2. **Конвеєрний рух по периметру (Closed Perimeter Conveyor):**
   - Верхня смуга рухається вправо $\rightarrow$, права — вниз $\downarrow$, нижня — вліво $\leftarrow$, ліва — вгору $\uparrow$.
   - 45° симетричні кутові шви плавно передають стібки між гранями без накопичення похибки.
3. **Гармонійна фаза хвиль ($C^\infty$ Standing Waves):**
   - Хвильовий фронт: $\sin(d \cdot \omega - 2\pi t)$.
   - При $t = 0 \Rightarrow \sin(d \cdot \omega)$.
   - При $t = 1 \Rightarrow \sin(d \cdot \omega - 2\pi) = \sin(d \cdot \omega)$.
   - Математична гладкість класу $C^\infty$ — жодного шва, хвилі розходяться безперервно.
4. **Різні чисті кольори без напівтонів (Ordered Dithering):**
   - Сувора заборона проміжних RGB-відтінків чи згладжування.
   - Усі спади, хвилі та інтенсивності формуються **виключно матричним дизерингом** (Bayer $4\times 4$) між чистими кольорами палітри (`#f4f1e8`, `#da2630`, `#da9220`, `#22446e`, `#30663c`, `#1c1e1a`).
5. **Генеративний перелив QR-коду:**
   - Модулі змінюють стан під дією інтерференції трьох гармонік (радіальна пульсація, діагональний дрейф, вихор).
   - Контрастність модулів залишається $\ge 4.8:1$, забезпечуючи 100% надійність зчитування камерою.
