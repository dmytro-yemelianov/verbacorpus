# Редактор гліфів Verba

Локальний застосунок macOS 14+ на AppKit/WKWebView. Працює без сайту, Worker,
інтернету, Electron або встановлення Python. Читає всі 2 266 шрифтових записи
поточного корпусу; читання гліфів іде сторінками через обмежений кеш.

## Запуск

```sh
# У корені репозиторію; app/node_modules після npm ci в app.
node desktop/glyph-editor/build.mjs
```

Відкрити `desktop/glyph-editor/dist/Verba Glyph Editor.app` у Finder.
Збірка прив’язує застосунок до `app/` цього checkout; сам корпус у пакет
не копіюється. Можна переміщувати `.app`, поки checkout залишається на місці.
Після переміщення checkout перебудуйте пакет або запустіть бінарник із
`--corpus /новий/шлях/app`.

## Робочий процес

1. Знайдіть шрифт у бібліотеці. Є колекції та черги непереглянутих,
   змінених і шрифтів із неповною українською абеткою.
2. Виберіть **Українська абетка**, **Усі вихідні гліфи**, **Без Unicode** або
   **Змінені / додані**. Пунктирна плитка означає відсутній символ; її вибір
   лише показує порожнє полотно, не додає вигаданий гліф у джерело.
3. Ліва кнопка малює, права або гумка стирає. Швидке перетягування не залишає
   дірок; один штрих — одна операція undo. Масштаб цілий, без згладжування.
4. Для відсутньої літери введіть основу (`Г`, `U+0413`, `g000030`) і натисніть
   **Скопіювати гліф**, потім домалюйте пікселі. Доступні зсув із обрізанням,
   дзеркалення, інверсія, очищення, розмір і горизонтальний крок.
5. Unicode-мапу можна додати до наявного немапованого гліфа або створити новий
   гліф для символу. Чужий уже зайнятий відповідник не замінюється мовчки.
6. **Переглянуто →** позначає гліф і переходить далі. **Шрифт переглянуто →**
   явно завершує перегляд шрифту й переходить до наступного. Це позначка
   людського перегляду, а не автоматична заява про повне українське покриття.
   Зміна гліфа скидає пов’язані позначки перегляду та статус шрифту.
7. Текстовий зразок показує поточні правки й рамки замість відсутніх символів.
   Лічильник українського покриття розділяє джерело та робочу правку.

Клавіші: `[`/`]` або `←`/`→` — гліфи; `PageUp`/`PageDown` — шрифти;
`Enter` — переглянути й далі; `⌘Enter` — завершити шрифт; `B`/`E` — інструмент;
`⌘Z`/`⌘Shift Z` — undo/redo; `⌘S` — негайне збереження; `⌘E` — експорт.
Поля введення зберігають звичайні текстові комбінації. Нативні меню підтримують
копіювання/вставлення та керування вікном.

## Збереження та експорт

Правки зберігаються автоматично приблизно через 300 мс після штриха/дії,
перед переходом до іншого шрифту та перед закриттям вікна/завершенням програми.
Оригінальні файли корпусу ніколи не перезаписуються.

Проєкт: `~/Library/Application Support/VerbaGlyphEditor/Projects/<snapshot>/`.
`fonts/<font-id>.json` містить повні змінені гліфи, створені ID, Unicode-мапи,
позначки перегляду, нотатки та ревізію; `session.json` — останній вибір і фільтри.
Файли пишуться атомарно; старі ревізії та невідповідний source SHA відхиляються.
Блокування проєкту запобігає одночасному редагуванню у двох процесах.

**Експорт шрифту** і **Експорт усіх правок** створюють окремі повні JSON-файли
Para Font Interchange 2.0 у `exports/`. Вони мають `kind: derived`, власний ID,
вихідні ліцензії й походження та журнал ручних змін. Українське покриття
перераховується з реальних непорожніх растрів. Експорт не публікує правки в API
та не змінює pinned snapshot. Кнопка **Папка правок** відкриває ці файли у Finder.
Експорти мають унікальні імена; попередній експорт не затирається.

## Перевірки

```sh
node --test desktop/glyph-editor/test.mjs
app/node_modules/.bin/tsc -p desktop/glyph-editor/tsconfig.json
node desktop/glyph-editor/build.mjs

# Кожна native-перевірка потребує окремого тимчасового проєкту:
GLYPH_TEST_PROJECT=$(mktemp -d)
'desktop/glyph-editor/dist/Verba Glyph Editor.app/Contents/MacOS/VerbaGlyphEditor' \
  --corpus "$PWD/app" --project "$GLYPH_TEST_PROJECT" --self-test

# Справжній WKWebView + файловий bridge + бар’єр збереження перед завершенням.
GLYPH_SMOKE_PROJECT=$(mktemp -d)
'desktop/glyph-editor/dist/Verba Glyph Editor.app/Contents/MacOS/VerbaGlyphEditor' \
  --corpus "$PWD/app" --project "$GLYPH_SMOKE_PROJECT" --smoke
```

Вісім модельних тестів перевіряють широкі рядки/padding, суцільні штрихи,
undo/redo, додавання українського гліфа, Unicode-мапи, трансформації,
інвалідацію перегляду та сумісний експорт зі збереженням ліцензії/джерела.
Вони й typecheck додані до Linux CI. Native self-test перевіряє атомарний
round-trip, заборону старих ревізій/чужого SHA та виходу за межі корпусу.

Ручна/браузерна перевірка на окремому тестовому проєкті підтвердила реальний
штрих мишею, undo/redo, review-next, відновлення після перезапуску й експорт.
Згенерований файл пройшов штатний `validateFont`; source SHA не змінився.
`--smoke` підтвердив запуск саме WKWebView та збереження перед завершенням.

Для інструментальної перевірки того самого UI/файлового сервісу є локальний
HTTP transport: `--serve-preview 8800 --resources <пакет>/Contents/Resources`.
Він слухає лише `127.0.0.1`, вимагає same-origin POST і призначений для розробки;
звичайний `.app` не відкриває порт і використовує WKScriptMessageHandler.

## Межі першої версії

Між шрифтами зберігаються правки, але undo-історія стосується поточного шрифту;
вона обмежена 128 діями та 8 MiB. Растр гліфа — до 1024 у кожному вимірі,
не більше 262 144 пікселів; це покриває всі поточні джерела (до 770×144).
Піксельні правки не генеруються автоматично. Вивід — канонічний JSON;
компіляція TTF/OTB і публікація у корпус — окремі подальші дії.
