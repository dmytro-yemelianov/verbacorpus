Shift+клік у черзі також додає підкладку. Блакитний знімок залишається під рисунком під час навігації. Поза растром обрізається. Видимий у режимі «Правка»; не входить у копію та експорт.

Комірка й метрики зберігаються. Пікселі за краєм обрізаються; ⌘Z повертає їх.

Геометрія та складання · поточний шрифт

Оберіть варіанти для відсутніх символів. Це заготовки для ручного перегляду; форма й базова лінія можуть потребувати правки. Складені гліфи підганяються по ширині без згладжування. Золота риска — базова лінія.

Референс → потрібні літери

Оберіть референсний шрифт або набір гліфів і потрібні символи. Retrieval добирає наявні форми схожих шрифтів, без дотренування. Можна вибрати до 64 гліфи референсу; результат додається у відкритий шрифт.

Референс і параметри

JSON: Para Font, набір glyphs або Para Glyph Region. BDF: ISO10646. TTF/OTF перетворюється на 1-bit растр без згладжування. Файл до 8 MiB; комірка й гліфи до 256 px. Для регіону без підпису введіть один референсний символ.

Варіанти гліфа

CNN і пошук схожого шрифту — експериментальні заготовки. Перевірте українську форму, діакритики й товщину штрихів. «Вибрати» замінює пікселі поточного гліфа одним undo; підкладка лишає його без змін.

Типографічні гайди шрифту

Усі значення у пікселях шрифту. Порожнє поле — автоматичний гайд цього шрифту: висоти вимірюються з його літер, базова лінія та інтервал — з метрик джерела. Кольорові стрілки показують відстань на схемі; 0 — базова лінія. Застосовується до всього шрифту, зберігається у правках та експорті. Растри й метрики окремих гліфів не пересуваються.
