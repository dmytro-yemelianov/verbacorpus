# Хендовер інтеграції корпусів Verba Corpus

Аудит стану на 1 листопада 2026 року; назви напрямів доповнено 2 листопада.
2 листопада реалізовано локальну парасольку з п’ятьма напрямами. Публічний сайт
ще працює в попередній структурі. HTTP-аудит нижче описує публічний стан
1 листопада; актуальна локальна реалізація описана в наступному розділі.

## Повний растровий корпус para.verba — 6 листопада 2026

Гілка `feat/para-font-corpus` тепер містить 2 266 записів із реальними растрами,
583 824 гліфи; metadata-only записів більше немає. Імпортовано всі 490 940
гліфів із 1 947 YAFF-файлів Hoard з перевіркою кожного пікселя. Збережено
88 773 гліфи без Unicode та 152 багатосимвольні відповідники. Para Font
Interchange 2.0.0 має власні ID гліфів, розміри та метрики кожного растра;
жодного штучного Unicode або масштабування під час імпорту немає.

REST: `/para/api/v2`, GraphQL: `/para/api/v2/graphql`. Старі шрифтові v1 URL
перенаправляються на v2; API прислів’їв `/api/v1` не змінено. Повний експорт
274 608 351 байт розбитий на 34 частини; читання гліфів використовує малі
індекси та сторінки, а не повне завантаження шрифту в Worker. У браузері є
каталог усіх шрифтів, сітка гліфів, перегляд і масштабування немапованих знаків.

Ліцензійний статус відділено від наявності растра: для Hoard збережено
NOASSERTION, unverified, null у redistributionAllowed і всі вихідні повідомлення.
Джерельні репозиторії не змінено. Деталі, команди та перевірки —
[PARA-FONT-CORPUS.md](PARA-FONT-CORPUS.md). Поточні перевірки: 186 Vitest,
сім Node-тестів, два цільові typecheck та збірка. Оновлений переглядач і профілювання:
[FONT-VIEWER-PERFORMANCE.md](FONT-VIEWER-PERFORMANCE.md). Cron, секрети та домени без змін.

## Реалізація парасольки

[Специфікація](superpowers/specs/2026-11-02-verba-umbrella.md) і
[план](superpowers/plans/2026-11-02-verba-umbrella.md) зберігаються в цьому репозиторії.
Локальна головна та `/corpora` показують `pro`, `contra`, `re`, `para`, `non`.
Входи: `/pro/`, `/contra/`, `/re/`, `/para/`, `/non/`. Старі адреси прислів’їв,
API, словника й блогу збережені; старий пошук із кореня веде до `/pro/`.
Погоджені піддомени розпізнає маршрутизатор, але DNS і доменні прив’язки не створені.

`app/sync_corpora.py` явно імпортує метадані UPA/Nasinnia й дозволений Cozette-зразок.
Збірка звіряє SHA-256 з `app/content/snapshots/manifest.json` і не потребує сусідніх
репозиторіїв. У публічній збірці є лише метадані UPA, шрифтовий зразок із ліцензією
та 12 авторських іконок із `app/content/pixel-icons.json`. Експорти лежать під
`/non/icons/`; реєстр — `/data/corpora.json`, хеші публічних знімків —
`/data/corpora-provenance.json`. Редакційний напрям використовує вже опубліковані статті.

Перевірки: [браузер](umbrella-browser.json), [HTTP і хеші](umbrella-http.json),
[прев’ю головної](previews/umbrella/home-1280.png). Деталі запуску й обмеження
типізації наведені в плані. Подальше розгортання має зберегти вимкнений новинний cron.

тут уже реалізовано каталог і навігацію. Новий репозиторій для хендовера не потрібен.
Виділення окремого репозиторію парасольки має сенс під час фактичного перенесення
головної сторінки на каталог, а прислів’їв — на окремий сайт. Це наступна
архітектурна зміна, яку ще не виконано.

Ревізії описують локальний стан, а не підтвердження публікації цих гілок на GitHub.
Перед початком звірити `git status` у кожному репозиторії. В UPA багато поточних
змін у генераторі, перегляді та тестах; їх не скидати й не підміняти старим комітом.
У Nasinnia також є незакомічена робота над генератором і журналом; git remote
на момент перевірки не налаштований. Не створювати замість нього новий шрифтовий проєкт.

## Назви напрямів парасольки

2 листопада власник погодив остаточну родину назв:
`pro.verba`, `contra.verba`, `re.verba`, `para.verba`, `non.verba`.
Це назви напрямів і цільові адреси, а не вже розгорнуті піддомени.
Власник уточнив принцип: використовувати відносно природні префікси до `verba`,
як `re-`, `pro-`, `contra-`, `para-`, `non-`, а не довільні назви предметів перед крапкою.

| Назва | Цільова адреса | Призначення | Статус назви |
| --- | --- | --- | --- |
| Verba Corpus | `verbacorpus.org` | Спільний каталог корпусів | Чинний бренд; перехід головної сторінки на каталог ще попереду |
| re.verba | `re.verbacorpus.org` | Редакція, історії з корпусів, переосмислення спадщини | Підтримано власником; це редакційний напрям, не окремий корпус |
| pro.verba | `pro.verbacorpus.org` | Прислів’я та приказки | Підтримано власником |
| contra.verba | `contra.verbacorpus.org` | «Українська без табу» | Підтримано власником |
| para.verba | `para.verbacorpus.org` | Шрифти й українські гліфи; Nasinnia | Погоджено власником |
| non.verba | `non.verbacorpus.org` | Візуальні колекції: орнаменти UPA та окрема колекція піксельних іконок | Погоджено власником |

`para.verba` утворено з опорою на поняття paraverbal typography: форма тексту
передає додатковий зміст. `non.verba` відсилає до nonverbal — візуальних знаків
і передавання змісту поза словами. Це брендові назви на основі термінів,
а не самостійні усталені типографічні терміни.

Бренди UPA Archive та Nasinnia зберігають назви своїх проєктів у каталозі й
атрибуції. Назва напряму не вимагає перейменовувати репозиторій, внутрішні ID
`slovo`/`bez-tabu`/`upa`, Worker або ресурси сховищ. Нові адреси підключати під час
окремого перенесення з перевіркою сумісності старих адрес.

### Nasinnia як основа шрифтового корпусу

`../nasinnia/README.md` описує каталог растрових шрифтів, API `/v1`, переглядач
`/explorer`, метрики й ліцензії, експорти JSON, PNG, PSF2, BDF та YAFF.
`wrangler.jsonc` налаштований для Worker `nasinnia` з D1 `nasinnia-catalog` і
R2 `nasinnia-fonts`. Наявність цих налаштувань не підтверджує поточний публічний
деплой; його адресу і стан треба перевірити перед додаванням активного посилання.

2 листопада у локальних JSON знайдено 321 запис із непорожніми `glyphData`.
Серед них лише `cozette-13x15` містить усі 33 великі й 33 малі українські літери.
У цьому записі також є `U+02BC` і `U+20B4`, `downloadAllowed: true`, ліцензія MIT.
Його файл має історичне ім’я `data/cozette-6x13.json`, але ID та нормалізована
комірка — `cozette-13x15`, 13×15. Перевірка означає наявність Unicode-гліфів;
візуальна якість українського набору потребує перегляду.

Для українського розділу потрібні явні фільтри повного й часткового покриття,
зразки слів, походження, ліцензія та окремий статус авторських або генерованих
наборів. Приватні дослідницькі результати Font Factory не прирівнювати до
опублікованих шрифтів. Metadata-only записи також не мають ставати завантажуваними
через додавання до парасольки.

Малий `../retro-pixel-factory/packages/timeline-schema/src/pixel-font.json`
можна додати окремим авторським зразком: він має 88 гліфів, усю велику українську
абетку і апострофи, але не має окремих малих літер. Це додаткове джерело,
основою шрифтового напряму залишається Nasinnia.

### Піксельні іконки та орнаменти

Власник запропонував додати піксельні іконки в естетиці вишивки та 8-бітної
графіки. Їхній погоджений напрям — `non.verba` поряд з UPA, зі збереженням
окремих колекцій історичних орнаментів і авторських іконок.

Початкова пропозиція: сітки 8×8, 16×16 і 32×32, обмежені палітри, узгоджені
товщина ліній і відступи. Можливі теми — птахи, рослини, хата, ремесла та
побутові предмети, а також кнопки пошуку, звуку, завантаження й збереження.
Використання: картки корпусів, Telegram, вебінтерфейси, ігри та LED-дисплеї.

Запис колекції має містити стабільний ID, матрицю, розмір, палітру, назву,
теги, автора, ліцензію й версію; для адаптації з UPA — посилання на вихідний
орнамент і опис змін. Експорти: SVG з цілими координатами, PNG у цілих масштабах,
JSON-матриця та спрайтшит. Авторські інтерпретації позначати окремо від оцифрованих
джерел. Перший набір ще не створено; окремий репозиторій поки не обрано.

### Кандидати на наступні корпуси

Це пропозиції розвитку, без зібраних у межах цієї роботи наборів чи призначених доменів.

| Напрям | Одиниця запису | Зв’язок з наявними корпусами |
| --- | --- | --- |
| Загадки, скоромовки, лічилки | Текст, відповідь за наявності, варіант, джерело | Вікторини й публікації для Telegram, доповнення усної традиції |
| Діалектні слова й назви | Словоформа, значення, місце, джерело, аудіо за наявності | Регіональні варіанти прислів’їв і словника |
| Голоси та вимова | Запис, транскрипція, прив’язка до тексту, згода й умови використання | Озвучення прислів’їв, слів і майбутніх діалектних записів |
| Українські вивіски та написи | Фото, транскрипція, місце, дата, походження | Історичні форми літер, зв’язок із Nasinnia |

Перший пріоритет — представити чотири наявні проєкти: прислів’я, «Без табу»,
UPA та Nasinnia. Наступним компактним текстовим набором можуть бути загадки,
скоромовки й лічилки; аудіо можна додавати як пов’язаний шар до наявних записів.

## Що вже реалізовано локально

### Каталог корпусів

- `app/content/corpora.json` — п’ять напрямів; вихідні ID `slovo`, `bez-tabu`, `upa` збережені.
- `app/content/corpora.html` і `app/build_corpora.mjs` — шаблон та генератор.
- `app/public/corpora.html`, `app/public/data/corpora.json` — результат збірки.
- `app/src/client/chrome.ts` — додає «Корпуси» в навігацію.
- `app/build.mjs` — збирає каталог разом із застосунком.

`slovo` посилається на `/pro/`, «Без табу» — на `/contra/`, UPA представлений
через `/non/` зі статусом підготовки архіву. Статистика UPA й Nasinnia походить
із перевірюваного знімка; версії джерел і хеші збережені в його метаданих.

### Українська без табу

Словник містить 2 000 вихідних рядків, 1 995 унікальних рядків, 55 іменованих
термінів і 12 груп. Є картки, пошук, фільтри, граф зв’язків, URL зі станом і
експорти CSV, JSON та XML. Це вибірка відповідників із проєкту на основі книжки
Лесі Ставицької, а не повний словник із визначеннями та цитатами.

Дані копіюються під час явного запуску `app/sync_bez_tabu.py` з сусіднього
репозиторію в `app/public/bez-tabu/data/`. Звичайна збірка працює без сусіднього
репозиторію, перевіряючи SHA-256 файлів за `provenance.json`. Автоматичної
синхронізації з upstream немає. Усі 5 повторних рядків і 26 рядків без терміна
збережено; `sourceRow` не є стабільним ID після переставлення рядків.

Пошук словника локальний у браузері. Нових серверних API та семантичного
індексу для нього немає. Інтерфейс український. Офлайн-кеш залежить від service
worker головного сайту; сам словник його не реєструє.

Повні деталі та попередні результати браузерних перевірок:
[BEZ-TABU.md](BEZ-TABU.md).

### UPA Archive та оздоблення

Актуальне джерело — `../upa-archive/data/patterns.v3.json`: 167 орнаментів,
геометрія заливок і стібків та походження від сторінок джерела. Окремий сайт
лежить у `../upa-archive/site/`. Його `wrangler.jsonc` має назву
`upa-local-preview`, вимкнені `workers_dev` і `preview_urls`, без доменних маршрутів.
Поточні умови публікації описані в `../upa-archive/site/README.md` і
`../upa-archive/docs/superpowers/specs/2026-10-22-upa-verbacorpus-site-design.md`.
Питання публічного поширення даних і джерельних зображень там залишено відкритим.

У Verba зараз три різні способи використання орнаментів:

1. `app/public/data/embroidery-archive.json` — стара вибірка 123 матриць для
   ефекту наведення. `app/src/client/main.ts` малює квадратні клітинки; схема
   `{r,c,m}` не містить повної геометрії нового UPA.
2. `app/src/shader/embroidery.ts` — 38 зафіксованих бордюрів для карток і GIF;
   `app/src/embroidery-css.ts` використовує їх для CSS-оздоблення.
3. `editorial/telegram/ornaments/` — нові підготовлені приклади з v3 через
   `chartSvg`, з маніфестом походження та хешем корпусу. Каталог `editorial/`
   наразі незакомічений і не підключений до звичайної збірки або бота.

Старий `app/scripts/build-embroidery-archive.mjs` читає абсолютний шлях
`/home/dmytro/github/dyco/assets/ukrainian-embroidery-corpus/unique_patterns.jsonl`.
Перед оновленням оздоблення замінити цей імпорт на відтворюваний знімок із UPA,
зберігши геометрію, ID орнаменту, версію й атрибуцію.

## Межі поточної інтеграції

`app/src/index.ts` завантажує лише прислів’я, пояснення та їхні метадані.
API v1, Vectorize, семантичний пошук і `app/src/telegram.ts` працюють із
прислів’ями. Спільного пошуку, універсального API корпусів, спільних ID та
автоматичного добору Telegram-публікацій зі словника чи UPA ще немає.

Раніше планувалися `slovo.verbacorpus.org` та `upa.verbacorpus.org`.
Поточні погоджені назви наведені вище: `pro.verba` для прислів’їв,
`non.verba` для візуальних колекцій разом з UPA та `para.verba` для Nasinnia.
Перенесення прислів’їв потребуватиме сумісності
старих `/p/*`, `/s/*`, `/card/*` та `/api/*`, включно з методом і тілом запитів
