# «Українська без табу» у Verba Corpus

Дата: 2026-10-25. Гілка `integrate/bez-tabu`, вихідна Verba — `34a2c10`.
Реалізація локальна; публічний Worker і DNS не змінено.

## Результат

- `/corpora` (`/corpora.html` перенаправляється статичними assets) — каталог
  прислів’їв, словника «Без табу» та UPA. Каталог збирається з
  `app/content/corpora.json` і шаблону `app/content/corpora.html`.
- `/bez-tabu/` — український інтерфейс словника, пошук по відповіднику, терміну та
  групі; фільтри групи, терміна й форми; по 60 записів, URL зі станом фільтрів.
  Порожній термін має окрему опцію. Результати вставляються через `textContent`.
- Дані завантажуються один раз і фільтруються локально; немає нових мережевих API,
  баз даних, авторизації чи серверних залежностей. Помилка завантаження показана
  явно, завантаження CSV/JSON/XML доступне й без JavaScript.
- Посилання «Корпуси» додано до навігації поточного сайту, включно з іншими мовами.
  Новий словниковий інтерфейс наразі лише український.
- UPA має статус «У підготовці · локальний перегляд», без публічного посилання.
  Прислів’я залишаються на своїх адресах та у своєму API.

## Дані та походження

Джерело: власний репозиторій користувача
<https://github.com/MurzikVasilyevich/ua-bez-tabu>, локальна копія поряд із Verba.
Він посилається на словник Лесі Ставицької «Українська мова без табу…».
Це вибірка відповідників, а не повний словник: визначення, цитати, сторінки та
стилістичні позначки у вихідній моделі відсутні.

Знімок: **2 000 рядків, 1 995 унікальних рядків, 55 іменованих термінів, 12 груп;
1 457 слів і 543 словосполучення** за ознаками джерела. Збережено 5 повторних
рядків, 26 рядків без терміна та 593 без емодзі. Немає довільних мовних виправлень.

Канонічний CSV має SHA-256:
`60e56c5e166a` — повний хеш у `app/public/bez-tabu/data/provenance.json`.
Там само — вихідна upstream-ревізія, локальна ревізія джерела, хеш експортера та
SHA-256 кожного імпортованого файла. `sourceRow` нумерує записи CSV із заголовком.
Після переставлення рядків він змінюється й не є постійним словниковим ID.

в репозиторії не описані. CC BY 4.0 іншого корпусу Verba цьому набору не призначено.

## Оновлення

```sh
cd ../ua-bez-tabu
python3 -m unittest discover -s tests -v
python3 tools/converter.py synonyms.csv data
cd ../verbacorpus/app
python3 sync_bez_tabu.py ../../ua-bez-tabu
npm run build
python3 -m unittest discover -s test -p 'test_sync_bez_tabu.py' -v
./node_modules/.bin/tsc -p tsconfig.corpora.json
npm test
./node_modules/.bin/wrangler dev --local --port 8791 --inspector-port 9235
```

Імпорт звіряє поля CSV/JSON і походження XML до запису. У звичайній збірці
перевіряються всі хеші знімка, тому сусідній репозиторій не потрібен, а випадкова
правка експортів зупинить збірку. Service worker оновлено до v32; для `/bez-tabu/`
використано network-first, щоб нова версія даних не залишалася в старому кеші.
Офлайн-перегляд можливий після кешування, якщо service worker Verba вже
зареєстровано на головному сайті. Словник сам його не реєструє й не змушує
відвідувача завантажувати великий початковий кеш прислів’їв.

## Перевірка

- Експортер ua-bez-tabu: 3 unittest пройшли, включно з повним roundtrip корпусу.
- Verba: 153 Vitest тести (23 файли) пройшли; нові тести перевіряють український
  пошук з апострофами, поєднання фільтрів, порожні терміни й збереження дублів.
- Нова браузерна частина проходить DOM-only `tsconfig.corpora.json`.
  Загальний `tsc --noEmit` має **35 тих самих діагностик, що й початковий коміт**
  (перевірено на окремо витягнутому baseline): GIF-типи, змішані Worker/DOM типи,
  Telegram і типи тестів. Нових діагностик немає; повний typecheck не став зеленим.
- Живий Wrangler і браузер: 2 000 результатів, додавання наступних 60,
  26 непідписаних термінів, URL replay, 1 457/543 за формою, 19 записів групи,
  дублікати, порожня видача, вхід з каталогу та навігація з `/en/`.
- При ширині 390 px обидві сторінки мають scrollWidth 390; п’ять експортів
  відповіли HTTP 200; необроблених винятків JavaScript не було.
  Машиночитний результат: `docs/bez-tabu-browser.json`.
- Імпорт знімка: 2 unittest пройшли (повна звірка полів і хешів; застарілий експорт
  відхиляється до будь-якого запису). Збірка з навмисно зміненим знімком відхиляється.
- `wrangler deploy --dry-run` пройшов; реального розгортання не було.

Браузерний тест користувався DOM-подіями через Superset CDP; це не окрема перевірка
всіх комбінацій фізичної клавіатури чи допоміжних технологій. Повний аудит мовних
значень і звірка з книжкою до цього кроку не входили.
